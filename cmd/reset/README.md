# Reset Code Generator

Автоматический генератор методов `Reset()` для Go структур.

## Описание

Этот инструмент сканирует все пакеты проекта, находит структуры с комментарием `// generate:reset` и генерирует для них методы `Reset()`, которые сбрасывают состояние объекта к значениям по умолчанию.

## Использование

### Запуск генератора

```bash
go run cmd/reset/main.go
```

или после установки:

```bash
go install ./cmd/reset
reset
```

### Пометка структур для генерации

Добавьте комментарий `// generate:reset` перед определением структуры:

```go
// generate:reset
type MyStruct struct {
    ID   int
    Name string
    Data []byte
}
```

После запуска генератора в том же пакете будет создан файл `reset.gen.go` с методом `Reset()`.

## Правила сброса

Генератор следует следующим правилам для разных типов полей:

### 1. Базовые типы

Сбрасываются к нулевым значениям:

- `int`, `int8`, `int16`, `int32`, `int64` → `0`
- `uint`, `uint8`, `uint16`, `uint32`, `uint64` → `0`
- `float32`, `float64` → `0`
- `string` → `""`
- `bool` → `false`

### 2. Слайсы

Обрезаются до нулевой длины (НЕ `nil`):

```go
r.Tags = r.Tags[:0]
```

Это сохраняет выделенную память и избегает повторных аллокаций.

### 3. Мапы

Очищаются с помощью функции `clear()`:

```go
clear(r.Metadata)
```

### 4. Указатели

Если указатель не `nil`, значение по указателю сбрасывается:

```go
if r.NamePtr != nil {
    *r.NamePtr = ""
}
```

### 5. Вложенные структуры

Если вложенная структура имеет метод `Reset()`, он вызывается:

```go
if r.Child != nil {
    r.Child.Reset()
}
```

### 6. Внешние типы из библиотек

Генератор распознает известные внешние типы и вызывает соответствующие методы:

- `*cache.Cache` (из `github.com/patrickmn/go-cache`) → вызывается `Flush()`:

```go
if r.Cache != nil {
    r.Cache.Flush()
}
```

## Пример

### Входной файл

```go
package model

// generate:reset
type User struct {
    ID       int
    Username string
    Email    *string
    Tags     []string
    Meta     map[string]interface{}
    Profile  *Profile
}

// generate:reset
type Profile struct {
    Bio   string
    Age   int
    Admin bool
}
```

### Сгенерированный файл (reset.gen.go)

```go
// Code generated by cmd/reset. DO NOT EDIT.

package model

// Reset resets User to its default state.
func (r *User) Reset() {
    if r == nil {
        return
    }

    r.ID = 0
    r.Username = ""
    if r.Email != nil {
        *r.Email = ""
    }
    r.Tags = r.Tags[:0]
    clear(r.Meta)
    if r.Profile != nil {
        r.Profile.Reset()
    }
}

// Reset resets Profile to its default state.
func (r *Profile) Reset() {
    if r == nil {
        return
    }

    r.Bio = ""
    r.Age = 0
    r.Admin = false
}
```

## Особенности

1. **Безопасность**: Все сгенерированные методы проверяют `nil` перед работой
2. **Производительность**: Слайсы обрезаются, а не создаются заново (избегаем аллокаций)
3. **Рекурсивность**: Автоматически вызывает `Reset()` для вложенных структур
4. **Идемпотентность**: Повторный вызов `Reset()` безопасен
5. **Не трогает capacity**: При обрезке слайсов сохраняется выделенная память

## Интеграция в CI/CD

### Проверка актуальности

Добавьте в CI скрипт проверки, что сгенерированные файлы актуальны:

```bash
# Генерируем файлы
go run cmd/reset/main.go

# Проверяем, есть ли изменения
git diff --exit-code '*.gen.go'
```

### Pre-commit hook

Создайте `.git/hooks/pre-commit`:

```bash
#!/bin/sh
go run cmd/reset/main.go
git add **/reset.gen.go
```

## Ограничения

1. Генератор не обрабатывает:
   - Приватные поля из других пакетов
   - Интерфейсные поля (невозможно определить конкретный тип)
   - Циклические зависимости между структурами

2. Массивы (не слайсы) не сбрасываются автоматически

3. Каналы и функции игнорируются

## Troubleshooting

### "go.mod not found"

Убедитесь, что запускаете генератор из корня проекта или его подкаталога.

### "failed to parse X"

Проверьте, что файл содержит валидный Go код. Генератор пропускает файлы с синтаксическими ошибками.

### Метод Reset() не генерируется

Убедитесь, что:
1. Комментарий `// generate:reset` находится прямо перед `type`
2. Это действительно структура (не интерфейс или alias)
3. Файл не называется `*_test.go` или `*.gen.go`
